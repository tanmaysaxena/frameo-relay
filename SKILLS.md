# Skills

Generated by `scripts/generate_skill_index.py`. Do not edit by hand.

| Skill | What it does |
|---|---|
| `frameorelay:conductor` | Use to run an approved Frameo relay job (frameo-jobs/<job-id>/relay.json) from references to finished clips. It is the only role allowed to spend credits. Locks references and style, makes keyframes, runs waves of clips with scene-prep and review subagents in parallel, keeps continuity by chaining real extracted frames, audits spend, and emits an ordered manifest. |
| `frameorelay:finish-cut` | Use after the conductor's clips and speech exist, to assemble the finished cut of a Frameo job. Reviews long clips for morph zones, cuts clean windows at a chosen pace, adds edge-to-edge halftone transitions, comic speech bubbles with name tags, narration caption boxes, a voice lane, ducked music beds, sound effects and a loudness-normalised mix, then listens to the result. Two free run_ffmpeg jobs (picture, then sound). Never touches the picture in the sound step. |
| `frameorelay:frameo-knowledge` | Use before planning or costing any Frameo job, and whenever Frameo's skills, models or prices may have changed. Reads the saved skills map, diffs it against the live Frameo MCP (free calls only), re-reads only changed skills, and updates the map so later plans are faster and cheaper. Never generates media or spends credits. |
| `frameorelay:panel-writer` | Use when a story, treatment or outline has NOT been broken down into a per-shot table, before the script-injector. Turns it into a production panel script made of a global style bible, then one table per shot (length, join, setup, cast, camera, visual prompt, dialogue bubbles, narration, SFX, BGM, AI-fill and owner-fill columns) and a production checklist, so parallel agents get every shot as a self-contained, unambiguous work order. Keeps the author's words exact, marks every invented line, checks the result with a validator, never spends credits. |
| `frameorelay:review` | Subagent role for the relay conductor. Independently inspects the REAL frames of one finished segment (identity, style, text and hands, and the join with the previous clip) and writes a verdict that cites the actual frames. Free, read-only against Frameo. Never spends credits. |
| `frameorelay:scene-prep` | Subagent role for the relay conductor. For ONE chain, finalize and seal its segment prompts against the locked style, cast and limits, and judge the keyframe still against the locks. Free, read-only against Frameo; writes only its own prep note. Never spends credits. |
| `frameorelay:script-injector` | Use when the user shares a script (story, ad, dialogue, scene list) to be made into a Frameo video. Turns the script into a validated plan (scenes, chains, cast, voices, style direction, dialogue, sealed prompts, cost), shows it for approval, then hands off to the conductor. Writes missing dialogue as clearly marked drafts. Never generates media or spends credits. |
